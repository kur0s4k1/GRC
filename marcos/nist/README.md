# NIST — Marcos de Ciberseguridad y Gestión de Riesgo

Referencia de los principales marcos del **NIST (National Institute of Standards and Technology)**, base frecuente para programas de seguridad, evaluación de controles y cumplimiento en EE.UU. y de adopción voluntaria internacional.

---

## NIST Cybersecurity Framework (CSF) 2.0

Marco de resultados organizado en **6 funciones** (la versión 2.0 añade *Govern*):

| Función | Propósito |
|---|---|
| **Govern (GV)** | Estrategia, roles, políticas, gestión de riesgo y cadena de suministro |
| **Identify (ID)** | Activos, contexto de negocio, evaluación de riesgo |
| **Protect (PR)** | Gestión de identidades, concienciación, protección de datos y plataformas |
| **Detect (DE)** | Monitoreo continuo, detección de eventos adversos y anomalías |
| **Respond (RS)** | Gestión de incidentes, análisis, mitigación y comunicación |
| **Recover (RC)** | Restauración de activos y operaciones |

> El CSF 2.0 no es prescriptivo: define **resultados** (*outcomes*) y se puede usar como capa de comunicación ejecutiva, mapeando a ISO/IEC 27001, CIS Controls y SP 800-53 para la implementación técnica.

## NIST SP 800-53 Rev.5 — Controles de seguridad y privacidad

Catálogo de controles organizado en **20 familias**. Ampliamente usado en el sector público de EE.UU. (FISMA/FedRAMP) y como referencia de catálogo de controles.

| Familia | Código |
|---|---|
| Control de acceso | AC |
| Concienciación y formación | AT |
| Auditoría y rendición de cuentas | AU |
| Evaluación, autorización y monitoreo | CA |
| Gestión de configuración | CM |
| Gestión de contingencia | CP |
| Identificación y autenticación | IA |
| Respuesta a incidentes | IR |
| Mantenimiento | MA |
| Protección de medios | MP |
| Seguridad física y ambiental | PE |
| Planificación | PL |
| Controles de personal | PS |
| Evaluación de riesgo | RA |
| Adquisición de sistemas y servicios | SA |
| Protección de sistemas y comunicaciones | SC |
| Integridad de sistemas e información | SI |
| Gestión de proveedores | SR |
| Protección de la privacidad | PT |
| Gestión de programas | PM |

---

## NIST SP 800-171 — Información No Clasificada Controlada (CUI)

Requisitos de protección de **CUI** en sistemas no federales (contratistas de defensa). 110 requisitos en 14 familias, alineado con SP 800-53. El **CMMC 2.0** se apoya en 800-171 para el nivel de certificación de contratistas.

## Gestión de riesgo

| Publicación | Uso |
|---|---|
| **SP 800-30 Rev.1** | Guía de evaluación de riesgo (identificación, análisis, respuesta) |
| **SP 800-37 Rev.2** | Risk Management Framework (RMF) — ciclo de autorización de sistemas |
| **SP 800-39** | Gestión de riesgo a nivel organizacional |
| **SP 800-61** | Guía de manejo de incidentes (preparación, detección, contención, recuperación) |
| **SP 800-53A** | Procedimientos de evaluación de controles |
